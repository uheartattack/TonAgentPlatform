## ☠️ Смертельные грабли
1. `git push origin main` с локалки = **force** (нет общего предка) = **уничтожит 609 коммитов Гоши**. НИКОГДА.
2. Деплой с локалки на прод = **затрёт прод-фиксы Гоши от 03.07** (Studio/Atlas/api). НЕ деплоить студию/api с локалки.
3. Прод прописан как git-remote с push-доступом → риск случайного push прямо на прод.
4. `contracts/` в `.gitignore` — 4 mainnet-контракта нигде не закоммичены (только диск + сервер).

## ✅ Безопасный порядок сведения (для Гоши)
1. **Бэкап всего** до любых действий: локальные незакоммиченные правки (`git stash` или архив), весь `contracts/`, прод-версии `src/api-server.ts` + `apps/landing/studio.*` (scp с сервера).
2. **Канон = GitHub `origin/main`.** Работать дальше от неё. Локальный орфан-main НЕ пушить.
3. **v3-работу перенести НА GitHub-линию заново** (не мержем орфан!): выделить v3-дельту (10 файлов `src/services/v3-*.ts`, v3-эндпоинты, 6 табов Studio, `agent.html`, `contracts/`) и приложить её поверх `origin/main` новыми коммитами / cherry-pick. Учесть, что api-server в каноне лежит в `src/api-server.ts`, а не в `agents/` — переносить туда.
4. **Сверить прод**: убедиться что прод = origin/main + v3-дельта; удалить протухший `src/agents/api-server.ts` на проде.
5. **`contracts/` убрать из `.gitignore` и закоммитить** (см. риск #4).
6. **Обезопасить prod-remote**: убрать push-URL или переключить на fetch-only.
