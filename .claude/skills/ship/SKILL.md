# /ship — чеклист перед деплоем

Реквизиты прода (хост, SSH-ключ, пути) — в локальном CLAUDE.md, секция «Прод». В этом файле их нет намеренно: он коммитится в публичную репу.

## 1. Чеклист (обязательный, останавливайся на первом красном)

1. **Типы:** `pnpm --filter @ton-agent/builder-bot exec tsc --noEmit` — ноль ошибок.
2. **Тесты:** `pnpm --filter @ton-agent/builder-bot test` — все зелёные. Красный тест = деплой отменён, сначала фикс.
3. **Секреты:** в диффе деплоящихся файлов нет ключей/токенов/мнемоник (`git diff` + поиск `API_KEY=`, `MNEMONIC=`, `BOT_TOKEN=`); `.env` не входит в список передаваемых файлов.
4. **Миграции БД:** новые таблицы/колонки оформлены как idempotent SQL в `src/db/schema-extensions.ts` (применятся при рестарте бота). Деструктивные изменения (DROP/ALTER с потерей данных) — стоп: сначала бэкап (`scripts/db-backup.sh`) и явное подтверждение пользователя.
5. **Git:** изменения закоммичены (conventional commit) и запушены ДО деплоя — на проде не должно оказаться кода, которого нет в репе.
6. **Landing:** если менялись файлы `apps/landing/` — соблюдён scp-протокол (источник истины — прод; см. CLAUDE.md): сначала забрали свежую версию с прода, правили её, только потом заливаем назад.
7. **Совместимость:** при точечном scp-деплое проверь, что изменённый файл не зависит от других изменённых, но не деплоящихся файлов (рассинхрон = падение на старте).

## 2. Последовательность деплоя

1. `scp -i <SSH_KEY> <изменённые файлы> root@<PROD_HOST>:<путь приложения>` — точечно, только изменённые файлы.
2. Менялись зависимости (`package.json`) → `ssh` на сервер → `pnpm install` в каталоге приложения.
3. `pm2 restart ton-agent-bot`
4. `pm2 logs ton-agent-bot --lines 50` — дождись стартовой сигнатуры (загрузка шаблонов/плагинов, `API Server running`) и понаблюдай 1–2 минуты на предмет ошибок.
5. **Smoke-тест:** бот отвечает на `/start`; Studio открывается на проде; если деплоился конкретный фикс — проверь именно его сценарий.
6. Откат при проблеме: задеплой предыдущую версию файла из git (`git show HEAD~1:<файл>`) тем же scp + restart.

## 3. После деплоя

- CHANGELOG.md → допиши изменение в `[Unreleased]`.
- BACKLOG.md → перенеси задачу в ✅ Done.
- Если в `[Unreleased]` накопилось ≥3 пунктов — предложи bump версии (см. правила в CLAUDE.md).
